🛠️ What is the purpose of your app? (which aspect of language learning it targets): By combining language learning with gameplay, this app helps learners study grammar (especially sentence structure and word order) and vocabulary at the same time without getting bored. Learners can also turn off the countdown timer and play without anxiety. Most importantly, language learning is built into the game itself, so learners don’t feel like they are taking a test. This avoids the “chocolate-covered broccoli” problem, where learning content is simply added on top of a game.
🚰 How long did you spend on it?:I spent 2 hours and used 199,372 tokens.
⏱️ What prompts did you give to make the app:
As following:
[Role] You are a full-stack web developer and game designer.
[Goal] Using HTML, CSS, and JavaScript (all in a single file for easy testing), build a web app called “Language Learning Plumber.”
[Feature Requirements]
Start screen: a Start button, Credits, and a custom question bank area.
Game screen: The inventory area provides different pipes depending on the question. Each pipe is labeled with a word, phrase, etc. The player takes pipes from the inventory area and places them in the answer area to build a connected pipeline. If the sentence formed by the connected pipes is grammatically correct, the player can open the faucet on the left side of the answer area, and the water flows through successfully. If the grammar is wrong, the water overflows.
Answer area: Depending on the question, the answer area is a grid of 5×5 or larger. Both the left and right sides of the answer area have connection ports.
Time limit: At the bottom of the screen, a pipe connects to the faucet in the upper left. Water slowly accumulates from the start of the level, representing the time limit. If the pipe fills up before the player opens the faucet, the player also loses the game.
[Output Format] Provide the complete code in a single HTML code block, including the styling and interaction logic.
